# warden

Администрирование сервера [NodeMP](https://docs.nodemp.com): группы с
уровнями и именованными правами, кик / бан / временный бан / белый список /
мьют / предупреждения, лимит машин на группу, выключатель спавна на весь
сервер, голосование за кик, чат-команды на русском и английском, журнал
аудита и игровая админ-панель на Dear ImGui игры, которую сервер сам отдаёт
каждому игроку — игроку ничего ставить не нужно. Управление панелью повторяет
CobaltEssentials Interface: у персонала она открыта по умолчанию, `/warden` в
чате скрывает и показывает её, клавишу можно назначить в настройках
управления игры. Все решения принимает сервер; панель только показывает и
просит.

## Установка

1. Скачайте `warden-<version>.zip` из
   [релизов](https://github.com/NodeMP-BeamNG/warden/releases) и распакуйте в
   корень сервера (папка с `Node-Server`): появятся `resources/warden/` и
   `content/warden.zip`.
2. Рядом поставьте ресурс `chat` (`examples/chat` из архива сервера): warden
   берёт команды из его события на шине и отвечает через него. Без ресурса
   chat включите `chat_fallback = true`.
3. Самой панели больше ничего не нужно: `resources/warden/client/warden/*.lua`
   лежит в том же архиве, сервер отдаёт эти файлы каждому входящему игроку.
   У персонала (`players.view`) она открывается сама; `/warden` (или `/wd`) в
   чате скрывает и показывает её, выбор запоминается на игрока.
   `content/warden.zip` — единственный маленький клиентский мод, который
   сервер раздаёт через лаунчер: он добавляет игровое действие **Toggle
   Warden panel** (Options > Controls > Warden) без клавиши по умолчанию —
   каждый игрок назначает свою. Оставьте архив в папке `content/` сервера
   (или в той, что указана в настройке `[Content] Folder`).
4. Впишите id своего аккаунта directory в `owner_ids` в
   `resources/warden/resource.toml` или положитесь на
   `directory_admin_is_owner` (администратор directory `ADM` — владелец).
   Запустите сервер; в логе будет `warden 0.2.0 ready: 5 group(s), ...`.

На сервере без `[Directory]` все игроки — гости с ключом по IP; владельца
тогда назначают правкой `data/players.json`
(`"ip:1.2.3.4": { "group": "admin" }`) — сама группа `owner` никогда не
хранится, только задаётся в конфиге.

## Группы и права

Игрок состоит в одной группе (`data/players.json`, иначе `default_group`).
У группы (`data/groups.json`) есть `level`, список `inherits` (от кого
наследует), список `perms` и `caps` (`vehicles`: сколько машин сразу, `-1`
без лимита). Пять групп из коробки:

| Группа | Уровень | Права (свои; остальные наследуются) | Машин |
|---|---|---|---|
| `default` | 0 | `votekick.vote` | 1 |
| `trusted` | 10 | `votekick.start` | 3 |
| `mod` | 50 | `players.view mod.kick mod.tempban mod.mute mod.warn car.delete audit.view votekick.cancel` | 5 |
| `admin` | 90 | `mod.ban mod.whitelist perms.set settings.read settings.write server.announce car.cap.bypass` | без лимита |
| `owner` | 100 | `*` | без лимита |

Правила, которые действуют везде (чат, панель): для действия нужно право;
действие над игроком требует **строго большего уровня**, чем у цели; группу
можно выдать только ниже своего уровня; `owner` берётся из `owner_ids` /
directory и никогда не назначается командой; `perms.manage` (правка групп,
по умолчанию только у владельца) не может выдать `*` или право, которого нет
у самого редактирующего. `mod.*` в `perms` группы — маска по префиксу.

`groups.json` можно править руками: файл перечитывается в течение секунды
(файл, который не разбирается, не трогается, об этом пишется в лог).

## Команды

Пишутся в чат. `<player>` — полное имя (без учёта регистра), `#<id>` для
игрока в сети или ключ `acct:<id>` / `ip:<addr>` (см. [Ограничения и
оговорки](#ограничения-и-оговорки)). Длительности — `30m`, `2h`, `7d`.

| Команда | Право | Что делает |
|---|---|---|
| `/help`, `/version`, `/whoami`, `/lang en\|ru` | — | Ваши команды, версия, ваша запись, ваш язык |
| `/warden`, `/wd` | — | Показать или скрыть панель (запоминается на игрока; назначенная клавиша делает то же) |
| `/players` | `players.view` | Кто в сети, с группой и уровнем |
| `/kick <player> [reason]` | `mod.kick` | Отключает с причиной |
| `/ban <player> [reason]` | `mod.ban` | Постоянный бан (аккаунт, если он подтверждён, и всегда IP) через список банов сервера |
| `/tempban <player> <duration> [reason]` | `mod.tempban` | Бан, который снимется сам |
| `/unban <player\|key>`, `/bans` | `mod.ban` | Снять бан; список банов |
| `/mute <player> [duration] [reason]`, `/unmute <player>` | `mod.mute` | Мьют (см. примечание) |
| `/warn <player> <reason>` | `mod.warn` | Предупреждение в записи; игроку сообщается |
| `/whitelist add\|remove <player> \| list \| on \| off` | `mod.whitelist` | Кому можно заходить |
| `/group <player> <group>`, `/groups` | `perms.set` / — | Перевести игрока; список групп |
| `/car delete [player]` | свои: — / чужие: `car.delete` | Удалить машины |
| `/votekick <player> [reason]`, `/vote yes\|no\|cancel` | `votekick.start` / `votekick.vote` / `votekick.cancel` | Голосование за кик |
| `/settings list \| get <key> \| set <key> <value> \| reset <key>` | `settings.read` / `settings.write` | Настройки на лету |
| `/audit [n]` | `audit.view` | Последние записи аудита |
| `/announce <text>` | `server.announce` | Строка всем |
| `/reload` | `server.reload` | Перезагрузить ресурс |

Мьют пока только предупреждающий: у платформы нет отменяемого события чата
(задача сервера #43), и warden не может остановить ресурс `chat` от
пересылки строки — поэтому замьюченному на каждую строку сообщается, что
он замьючен. Когда событие появится, впишите его имя в `chat_veto_event`, и
строки будут глушиться.

## Панель

### Управление

- Окно `Warden vX.Y.Z` **открыто по умолчанию** у игрока с `players.view`
  (`ui.default_shown`); у обычного игрока скрыто.
- **`/warden`** (или `/wd`) в чате скрывает и показывает его. Крестик окна
  делает то же. Выбор запоминается на игрока на сервере (`data/ui.json`)
  вместе с масштабом UI и переживает перезаход.
- **Своя клавиша**: Options > Controls > **Warden** > *Toggle Warden panel*.
  Клавиши по умолчанию нет; действие приходит из `content/warden.zip`,
  который лаунчер ставит на время сессии. Фиксированной клавиши больше нет
  (встроенная клавиша 0.1.0 убрана).
- Консоль: `nodemp_wd.toggle()`.
- При первом hello сессии персонал получает одну строку в чат об этом
  (`ui.welcome`).

### Структура

Одно окно в форме CobaltEssentials Interface: панель **QuickInfo** (имя
сервера, игроки и машины из лимитов, ваша группа и индикаторы `Спавн`, `Белый
список`, `Гости`, `Голосование` — `>>` зелёный «открыто / разрешено», `X`
красный «выключено / закрыто», `//` жёлтый пока идёт голосование, с
секундами), поле **масштаба UI** со сбросом и выбор языка, затем вкладки. Что
видно во вкладке, зависит от прав, а кнопка, которую отклонило бы правило
уровней, серая — сервер всё равно проверяет каждый запрос, и его отказ
печатается под строкой. Кнопка, для которой у платформы пока нет вызова, тоже
серая, а её подсказка называет задачу сервера.

| Вкладка | Нужно | Что показывает |
|---|---|---|
| Игроки | `players.view` | Ряд быстрых действий на весь сервер (выключить / включить спавн с `settings.write`, белый список вкл / выкл с `mod.whitelist`, объявление с `server.announce`; «заморозить / разморозить всех» и «заглушить / запустить всех» серые до server #58 / #89), затем сворачиваемый заголовок на каждого игрока — имя, группа и уровень, машины, гость / мьют / в белом списке — окрашенный по группе. В раскрытом: маленькие кнопки Голосование за кик, Кик, Бан, Временный бан, Мьют или Снять мьют, В белый список или Из белого списка, Предупредить, Камера (на машину игрока, на клиенте; в строгой сессии недоступна), Телепорт к / ко мне (серые до server #53); поля Причина и Срок (30m / 2h / 1d / 7d / другой), которые кнопки читают; Бан и Временный бан просят второй клик. Узлы `машины` (машины, известные клиентскому моду, удалить одну или все; заморозить и запустить серые), `сведения` (id, аккаунт, ключ, IP, входы, первый вход, предупреждения, лимит, мьют, имена, пинг, время в сети) и `права` (группа с «Применить» / «Снять» для `perms.set`). |
| Настройки | — | `Warden`: группы (таблица всем; редактор — имя, уровень, наследование, права, машины — с `perms.manage`, по тем же правилам, что на сервере: только ниже своего уровня, только то, что есть у самого), белый список (вкл / выкл, добавить, убрать), настройки панели (показана по умолчанию, приветствие, спавн машин) и таблица настроек на лету с полями по типу и сбросом (`settings.read`, `settings.write`). `Сервер`: имя, карта, версия, максимум игроков и машин — только просмотр, правка на лету требует server #39. `Интерфейс`: тема (`cobalt` / `game`), масштаб UI, язык. |
| Окружение | — | Заглушка до server #52 (время суток и погода с сервера); показывает время суток вашей игры. |
| База | любое из `mod.ban`, `mod.mute`, `mod.whitelist`, `audit.view` | Баны с «Разбанить», действующие мьюты с «Снять мьют», записи белого списка с «Убрать» и последние N записей аудита. |

Идущее голосование за кик показывается баннером сверху экрана — счёт,
секунды, кнопки «За» / «Против» (`votekick.vote`) или «Отменить»
(`votekick.cancel`) у тех, кому это разрешено, — независимо от того, открыто
ли окно. Панель говорит на языке `/lang` (или сервера), переключается в самом
окне; тексты берутся из тех же `lang/*.json`, что и строки чата.

Панель — обычный Lua на Dear ImGui игры: отдаётся при каждом входе и
исчезает при выходе с сервера; кода от сервера она не получает, только
данные JSON. Текстовое поле панели пока не отбирает клавиатуру у машины —
остановитесь, прежде чем печатать причину.

## Ограничения и оговорки

- **Гость — это его адрес.** Игрок без аккаунта directory хранится по IP:
  бан или белый список для гостя действуют на всех за этим адресом (NAT,
  общий хостинг), а гость, пришедший с нового адреса, — новый игрок.
  Надёжная личность есть только у аккаунта directory.
- **Имя само по себе никого не пускает.** Записи `name:` в белом списке
  пускают только вошедшие аккаунты; имя гостя — то, что он сам напечатал,
  поэтому гостя такая запись не пустит. Без directory добавляйте в белый
  список по `#pid` или по ключу `ip:` (`/whitelist add <имя>` так и ответит).
- **Голосование за кик выключено по умолчанию.** Голоса считаются по
  личности (все гости за одним адресом — один голос), паузы переживают
  перезапуск, но марионетки с разных адресов всё равно считаются. Включайте
  осознанно.
- **Цель указывается точно.** `/group`, `/whitelist add`, `/ban` и все
  остальные команды, которые что-то меняют, требуют полное имя, `#pid` или
  ключ; начало имени никому не подходит. Имя, которое подключённый гость
  делит с известным игроком, отклоняется как неоднозначное — укажите `#pid`
  или ключ.
- **`chat_fallback = true` без ресурса `chat`**: строки `player:tell` некому
  показать, и игроки без панели не получают ответов.
- **Адреса видны с `mod.ban` и выше.** Группам ниже они показываются
  скрытыми в панели и в аудите.
- **Мьют пока предупреждающий** — до отменяемого события чата на сервере
  (server #43). **Текстовые поля панели** пока не отбирают клавиатуру у
  машины.
- **Клавише нужен content-архив.** Игра читает действия ввода только из
  файлов (NodeMP #49), поэтому назначаемое действие едет как
  `content/warden.zip` через лаунчер; сама панель, `/warden` и консоль
  работают и без него. «Камера» —
  клиентская и в строгой сессии недоступна; телепорт, заморозка и удалённый
  запуск ждут серверных вызовов (#53, #58, #89).

## Хранилище

Всё — JSON в `resources/warden/data/`, пишется атомарно (временный файл +
переименование, предыдущая версия остаётся как `.bak`) и не чаще раза в
секунду на файл:

| Файл | Содержимое |
|---|---|
| `groups.json` | Группы (можно править) |
| `players.json` | Запись на ключ игрока: группа, имена, входы, первый/последний визит, предупреждения, мьют, язык |
| `whitelist.json` | Записи белого списка (`acct:`, `ip:` или `name:` для ещё не виденного игрока) |
| `bans_meta.json` | Кто забанил, почему, до когда; сами баны — серверные (`bans.json`) |
| `settings.json` | Переопределения настроек |
| `ui.json` | На игрока (по ключу): панель показана или скрыта, масштаб UI; размер ограничен, первыми уходят давно не виденные записи |
| `audit/YYYY-MM-DD.jsonl` | Объект JSON на каждое действие или отказ; старше `audit.retain_days` удаляются |

## Другим ресурсам

Через шину сервера (`node.bus`), JSON: спросите `warden:getGroup
{ pid | key, tag? }` и получите `warden:group { key, group, level, perms, tag }`;
спросите `warden:hasPerm { pid | key, perm, tag? }` и получите `warden:perm { ok, ... }`.
warden публикует `warden:ready`, `warden:groupChanged { key, group, pid? }` и
`warden:groupsChanged`.

## Обновление

Распакуйте новый релиз поверх старого. `data/` в архив никогда не входит.
Новая версия может добавить группы или права в значения по умолчанию;
существующий `groups.json` не меняется — `/groups` и панель показывают то,
что у вас есть.

С 0.1.0: ключ конфига `ui.key` убран (оставшееся в `resource.toml` значение
просто не читается); панель открывается сама у персонала
(`ui.default_shown`); появился `content/warden.zip` — держите его в
`content/` ради назначаемой клавиши; протокол панели — 2 (сервер сам отдаёт
