**warden** — открытый плагин администрирования для сервера NodeMP:
группы с уровнями и правами, кик / бан / временный бан / белый список /
мьют / предупреждения, лимит машин на группу, голосование за кик,
чат-команды на русском и английском, журнал аудита и панель в игре
(клавиша F9, Dear ImGui игры). Все решения принимает сервер: панель только
показывает и просит.

Репозиторий: [NodeMP-BeamNG/warden](https://github.com/NodeMP-BeamNG/warden)
— серверный ресурс вместе с клиентской половиной панели, один архив.
Лицензия — GPL-3.0-or-later.

## Установка

1. Скачайте `warden-<version>.zip` из релизов `warden` и распакуйте в корень
   сервера — папку, где лежит `Node-Server`. Появится `resources/warden/`.
2. Рядом должен стоять ресурс `chat` (`examples/chat` из архива сервера):
   warden получает команды из его события `chat:command` и отвечает через
   него системными строками.
3. Панель уже в архиве: `resources/warden/client/warden/*.lua` — клиентские
   файлы, которые сервер отдаёт каждому входящему игроку при подключении.
   Игрок ничего не устанавливает; в игре панель открывается на **F9** (или
   командой `/wd` в чате).
4. Откройте `resources/warden/resource.toml` и впишите id своего аккаунта
   directory в `owner_ids`. Администратор directory (роль `ADM`) — владелец
   и без этого (`directory_admin_is_owner = true`).
5. Запустите сервер. В логе: `warden 0.1.0 ready: 5 group(s), 0 player record(s), whitelist off, votekick off`.

```toml
# resources/warden/resource.toml
[config]
language = "ru"
owner_ids = [12345]
```

Сервер без `[Directory]`: все игроки — гости, ключ записи — IP. Владельца
тогда назначают правкой `resources/warden/data/players.json`:
`"ip:1.2.3.4": { "group": "admin" }`.

## Группы и права

Игрок состоит в одной группе. У группы есть **уровень**, список групп, от
которых она **наследует** права, список **прав** и **лимиты** (`vehicles` —
сколько машин можно иметь одновременно; `-1` — без лимита). Из коробки:

| Группа | Уровень | Свои права | Машин |
|---|---|---|---|
| `default` | 0 | `votekick.vote` | 1 |
| `trusted` | 10 | `votekick.start` | 3 |
| `mod` | 50 | `players.view`, `mod.kick`, `mod.tempban`, `mod.mute`, `mod.warn`, `car.delete`, `audit.view`, `votekick.cancel` | 5 |
| `admin` | 90 | `mod.ban`, `mod.whitelist`, `perms.set`, `settings.read`, `settings.write`, `server.announce`, `car.cap.bypass` | без лимита |
| `owner` | 100 | `*` | без лимита |

Правила действуют одинаково в чате и в панели:

- для действия нужно право;
- действие над игроком требует **строго большего уровня**, чем у цели;
- выдать можно только группу **ниже своего уровня**;
- группа `owner` задаётся только в конфиге или directory — командой её не выдать;
- правка групп (`perms.manage`, по умолчанию только у владельца) не может
  выдать `*` или право, которого нет у редактирующего.

Группы лежат в `resources/warden/data/groups.json`; файл можно править
руками — он перечитывается в течение секунды.

```json
"helper": {
  "level": 20,
  "inherits": ["trusted"],
  "perms": ["mod.warn", "mod.mute"],
  "caps": { "vehicles": 4 }
}
```

## Команды

Пишутся в чат с префиксом `/`. `<player>` — полное имя игрока (регистр не
важен), `#<id>` для игрока в сети, либо ключ `acct:<id>` / `ip:<addr>` (см.
«Ограничения и оговорки»). Длительности — `30m`, `2h`, `7d`.

| Команда | Право | Действие |
|---|---|---|
| `/help` | — | Команды, доступные вам |
| `/whoami`, `/version`, `/lang en\|ru` | — | Ваша запись, версия, язык ответов |
| `/wd` | — | Показать или скрыть панель (то же, что F9) |
| `/players` | `players.view` | Кто в сети, группа и уровень |
| `/kick <player> [причина]` | `mod.kick` | Отключить |
| `/ban <player> [причина]` | `mod.ban` | Постоянный бан (аккаунт и IP) |
| `/tempban <player> <срок> [причина]` | `mod.tempban` | Бан на срок |
| `/unban <player\|ключ>`, `/bans` | `mod.ban` | Снять бан, список банов |
| `/mute <player> [срок] [причина]`, `/unmute <player>` | `mod.mute` | Мьют |
| `/warn <player> <причина>` | `mod.warn` | Предупреждение |
| `/whitelist add\|remove <player>`, `/whitelist list\|on\|off` | `mod.whitelist` | Белый список |
| `/group <player> <группа>`, `/groups` | `perms.set` | Перевести игрока, список групп |
| `/car delete [player]` | `car.delete` (свои — без права) | Удалить машины |
| `/votekick <player> [причина]`, `/vote yes\|no\|cancel` | `votekick.start` / `votekick.vote` / `votekick.cancel` | Голосование за кик |
| `/settings list\|get\|set\|reset` | `settings.read` / `settings.write` | Настройки на лету |
| `/audit [n]` | `audit.view` | Журнал |
| `/announce <текст>` | `server.announce` | Строка всем |
| `/reload` | `server.reload` | Перезагрузить ресурс |

Баны хранит сам сервер (`bans.json`): забаненный не доходит до плагина,
его отсекает ядро. warden добавляет к бану автора, причину и срок
(`data/bans_meta.json`) и снимает временные баны по таймеру.

Мьют пока предупреждающий: платформа ещё не даёт ресурсу отменить строку
чата, поэтому замьюченному сообщается о мьюте на каждую строку. Когда
появится отменяемое событие чата, его имя вписывается в
`chat_veto_event`, и строки будут глушиться.

## Голосование за кик

Игрок с правом `votekick.start` (по умолчанию `trusted` и выше) пишет
`/votekick <player> [причина]`. Все остальные голосуют `/vote yes` или
`/vote no` (в панели — кнопками). Голосование проходит, когда «за» набирает
`votekick.threshold` от числа голосующих (все в сети, кроме цели; 0.6 =
60 %) и больше, чем «против»; длится `votekick.window_sec` секунд; не
начинается, если игроков меньше `votekick.min_players`; игроков уровня
`votekick.immune_level` и выше кикнуть голосованием нельзя; после
голосования цель и инициатор ждут `votekick.cooldown_sec`. `mod` и выше
могут отменить голосование (`/vote cancel`).

## Панель

Открывается на **F9** (клавиша задаётся ключом `ui.key`) или командой `/wd`.
Что видно, зависит от прав:

- **Игроки** (`players.view`) — все в сети с id, аккаунтом, группой, машинами,
  пингом и временем в сети; у выбранного игрока — запись (ключ, IP, входы,
  предупреждения, мьют, лимит) и действия: кик, предупреждение, мьют,
  временный бан, бан, группа, удаление машин, белый список, голосование за
  кик. Причина, срок (30m / 2h / 1d / 7d / другой) и группа вводятся в
  форме под списком. Кнопка, которую сервер отклонил бы (нет права или
  цель не ниже по уровню), серая.
- **Группы** — уровень, наследование, лимит и права каждой группы (только
  просмотр; группа игрока меняется во вкладке «Игроки»).
- **Настройки** (`settings.read`, правка — `settings.write`) — настройки
  на лету с полями по типу и сбросом к значению из `resource.toml`.
- **Аудит** (`audit.view`) — последние записи журнала.
- **Баны** (`mod.ban`) — список банов и «Разбанить».

Баннер идущего голосования (счёт, секунды, «За» / «Против» / «Отменить» по
правам) виден сверху экрана и при закрытом окне. Язык панели — язык `/lang`
игрока или сервера, переключается в окне.

Панель — клиентский Lua на Dear ImGui игры, который сервер отдаёт при входе;
кода от сервера она не получает, только данные. Панель ничего не решает
сама: каждая кнопка — запрос `wd:req` серверу, который проверяет право,
уровень и аргументы так же, как для чат-команды, и пишет запись в аудит.
Текстовое поле панели пока не отбирает клавиатуру у машины — остановитесь,
прежде чем печатать.

## Ограничения и оговорки

- **Гость — это его адрес.** Игрок без аккаунта directory хранится по IP:
  бан или белый список для гостя действуют на всех за этим адресом (NAT,
  общий хостинг), а гость, пришедший с нового адреса, — новый игрок.
  Надёжная личность есть только у аккаунта directory.
- **Имя само по себе никого не пускает.** Записи `name:` в белом списке
  пускают только вошедшие аккаунты; имя гостя — то, что он сам напечатал,
  поэтому гостя такая запись не пустит. Без directory добавляйте в белый
  список по `#pid` или по ключу `ip:` (`/whitelist add <имя>` так и ответит).
- **Голосование за кик выключено по умолчанию.** Голоса считаются по
  личности (все гости за одним адресом — один голос), паузы переживают
  перезапуск, но марионетки с разных адресов всё равно считаются. Включайте
  осознанно.
- **Цель указывается точно.** `/group`, `/whitelist add`, `/ban` и все
  остальные команды, которые что-то меняют, требуют полное имя, `#pid` или
  ключ; начало имени никому не подходит. Имя, которое подключённый гость
  делит с известным игроком, отклоняется как неоднозначное — укажите `#pid`
  или ключ.
- **`chat_fallback = true` без ресурса `chat`**: строки `player:tell` некому
  показать, и игроки без панели не получают ответов.
- **Адреса видны с `mod.ban` и выше.** Группам ниже они показываются
  скрытыми в панели и в аудите.
- **Мьют пока предупреждающий** — до отменяемого события чата на сервере
  (server #43). **Текстовые поля панели** пока не отбирают клавиатуру у
  машины (планируется в 0.1.1).

## Настройка

`resources/warden/resource.toml`, секция `[config]`. Все ключи
необязательны. Ключи, помеченные «на лету», меняются командой
`/settings set <ключ> <значение>` (или в панели) и сохраняются в
`data/settings.json`.

| Ключ | По умолчанию | На лету | Описание |
|---|---|---|---|
| `language` | `"en"` | да | Язык сообщений сервера (`en` / `ru`) |
| `owner_ids` | `[]` | | Id аккаунтов directory — владельцы |
| `directory_admin_is_owner` | `true` | | Администратор directory (`ADM`) — владелец |
| `allow_guests` | `true` | да | Пускать игроков без аккаунта directory |
| `role_tag` | `true` | да | Показывать группу тегом рядом с ником |
| `default_group` | `"default"` | | Группа нового игрока |
| `chat_fallback` | `false` | | Читать `chat:send` напрямую (нет ресурса chat) |
| `chat_veto_event` | `""` | | Имя отменяемого события чата, когда появится |
| `whitelist.enabled` | `false` | да | Пускать только из белого списка |
| `votekick.enabled` | `false` | да | Голосование за кик (выключено по умолчанию) |
| `votekick.threshold` | `0.6` | да | Доля голосов «за» |
| `votekick.min_players` | `4` | да | Минимум игроков в сети |
| `votekick.window_sec` | `60` | да | Длительность голосования |
| `votekick.cooldown_sec` | `300` | да | Пауза для цели и инициатора |
| `votekick.immune_level` | `50` | да | Уровень, с которого не кикают |
| `limits.commands_per_10s` | `8` | | Команд от игрока за 10 с |
| `limits.ui_per_sec` / `limits.ui_per_min` | `10` / `120` | | Кадров `wd:req` от клиента |
| `audit.enabled` | `true` | | Писать журнал |
| `audit.retain_days` | `90` | | Срок хранения журнала |
| `ui.key` | `"F9"` | | Клавиша панели (имя клавиши Dear ImGui: `F9`, `F7`, `Insert`) |

## Файлы данных

`resources/warden/data/` — JSON, пишется атомарно и не чаще раза в секунду:
`groups.json` (группы), `players.json` (записи игроков: группа, имена,
входы, предупреждения, мьют, язык), `whitelist.json`, `bans_meta.json`,
`settings.json`, `audit/YYYY-MM-DD.jsonl` (журнал, по строке на действие
или отказ). При обновлении плагина `data/` не трогается.

## Другим ресурсам

Через шину сервера: `warden:getGroup { pid | key, tag? }` → `warden:group
{ key, group, level, perms, tag }`; `warden:hasPerm { pid | key, perm, tag? }`
→ `warden:perm { ok, ... }`. warden публикует `warden:ready`,
`warden:groupChanged` и `warden:groupsChanged`. Так любой ресурс может
читать группы warden, не завися от его кода.
